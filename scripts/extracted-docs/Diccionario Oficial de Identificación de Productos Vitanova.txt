

Diccionario Oficial de Identificación de 
Productos Vitanova 
Objetivo 
Este documento ayuda a MIA a identificar correctamente el producto que busca el cliente 
cuando este utiliza nombres comunes, descripciones, síntomas o necesidades en lugar del 
nombre oficial. 
Reglas generales 
● Un mismo producto puede ser mencionado de muchas formas. 
● MIA debe interpretar la intención del cliente antes que buscar únicamente el nombre 
oficial. 
● Si un cliente utiliza cualquiera de las palabras o frases descritas en este documento, 
MIA debe relacionarlas con el producto correspondiente. 
● Si existe duda entre dos productos, MIA debe hacer una pregunta breve para identificar 
cuál necesita el cliente. 
● Nunca debe recomendar un producto distinto únicamente porque compartan alguna 
palabra similar.

Reglas de decisión 
Neurofeet vs Neurotin 
Si el cliente habla de: 
● piernas 
● pantorrillas 
● circulación 
● várices 
● piernas cansadas 
● piernas pesadas 
● debajo de la rodilla 
MIA debe identificar Neurofeet. 

 
Si el cliente habla de: 
● pie 
● tobillo 
● talón 
● planta del pie 
● arco del pie 
● dedos 
● calcetín corto 
● punta abierta 
MIA debe identificar Neurotin. 
 
Si el cliente únicamente menciona: 
"Quiero unos de compresión." 
MIA debe preguntar: 
¿Buscas compresión para toda la pierna (debajo de la rodilla) o únicamente 
para el pie y el tobillo? 
Solo después de la respuesta debe recomendar uno de los dos productos. 
 
Regla de interpretación 
Antes de responder que no existe información sobre un producto, MIA debe intentar identificar 
la intención del cliente. 
Ejemplos: 
"Tengo mucha panza." 
 → Back2Fit. 
"Me da pena usar sandalias." 
 → Clean Nails. 
"Trabajo todo el día parado y termino con las piernas muy cansadas." 
 → Neurofeet. 

"Solo me duele el tobillo y la planta del pie." 
 → Neurotin. 
"Quiero ocultar mis canas." 
 → Bye Canas. 
"Tengo una boda y quiero levantar un poquito la cara." 
 → Bella Patch. 
 
Palabras que NO identifican un producto 
Las siguientes palabras son demasiado generales y por sí solas no deben hacer que MIA 
asocie un producto específico: 
● ayuda 
● información 
● catálogo 
● producto 
● precio 
● promoción 
● descuento 
● envío 
● entrega 
● compra
