# Simulaciones conversacionales — Protocolo (decisión del Concilio por práctica)

**Método:** el Concilio decide la **siguiente falsación empírica** no por preferencia, sino por lo que las conversaciones simuladas revelan. Cada candidato se estresa con la pregunta falsacional que le corresponde y se puntúa con la rúbrica del Concilio.

**Límite epistemológico (obligatorio):** estas conversaciones son **simuladas** — no confirman ni refutan ningún principio. Solo estiman la **falsabilidad** de cada candidato: qué tan observable es su señal, qué tan limpio se puede construir el caso donde debe fallar, y qué cambiaría en la estructura si la falsación tuviera éxito. **La simulación elige el blanco; la evidencia real (meta-análisis) dará el veredicto.**

## Convenciones de etiquetado

- `[estado]` → estado del Atlas ocupado por la evidencia del turno (`explorando`...`reticente`, `desenganchado`).
- `[obs]` → observable del Diccionario (`kb/observables.md`) que se dispara.
- `[fuerza]` → principio (P-xxx) que actúa en el turno.

## Rúbrica del Concilio (1–5)

| Dimensión | Pregunta |
|---|---|
| **O — Observabilidad** | ¿La señal se dispara de forma natural en lenguaje de compra real? |
| **D — Discriminabilidad** | ¿Puedo construir el escenario conversacional donde la predicción del principio DEBE fallar si es falso, de forma limpia y aislada? |
| **S — Peso estructural** | ¿Una falsación exitosa refina o **rompe** estructura (estados/reglas Fundamental)? |
| **C — Coste de evidencia** (invertido: 5 = barato/accesible) | ¿Cuánto pesa el meta-análisis que la decidiría? |

**Puntaje = O × D × S / C.** El Concilio elige el máximo.
